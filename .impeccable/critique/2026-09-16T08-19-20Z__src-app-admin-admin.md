# 어드민 크리틱 — src/app/(admin)/admin

대상: 어드민 전 화면(로그인 · 사이트 설정 · 페이지 관리 · 페이지 구성). 브라우저 검사는 로그인 없이 열리는 `/admin/login`과 공개 홈 `/`에 한정. 나머지는 소스 리뷰.

## Anti-Patterns Verdict

**LLM 평가**: 어드민 자체는 AI 슬롭 티가 크게 나지 않는다. 토큰이 있고, 카드 격자 반복·그라데이션·이모지 아이콘이 없다. 다만 "만든 사람 냄새"가 없다 — 어디를 봐도 이 사무소·이 변호사의 것이라는 표식이 없다(사이드바 ADMIN 글자만). product 레지스터라 과한 개성은 불필요하지만, 사무소 이름과 사이트 바로가기 정도는 있어야 "내 도구"로 느껴진다.

**결정적 스캔** (impeccable detect, 브라우저 모드):
- `/admin/login` — 1건: `flat-type-hierarchy` (11/12/13/16/20px, 최대 비 1.8:1). 제목 20px 이 작다.
- `src/app/(admin)` 소스 정규식 스캔 — 0건.
- `/` 공개 홈 — 20건. 어드민 대상이 아니지만 **어드민이 만든 결과물**이므로 기록:
  - `low-contrast` 15건: 강조색 `#d85a30` 흰 배경 3.9:1(필요 4.5), 연한 강조 `#f0997b` 2.2:1, 버튼 흰 글자/주황 배경 3.9:1. 히어로 사진 위 글자 1.7:1(필요 3:1). **이 색은 코드가 아니라 `site_settings`에서 온다** — 어드민 색 설정이 대비를 검사하지 않는다는 뜻.
  - `hero-eyebrow-chip` 1, `repeated-section-kickers` 3 (PRACTICE-AREAS / CASES / YOUR SITUATION), `single-font` 1.

**시각 오버레이**: 브라우저 주입 없이 헤드리스 스캔만 수행. 사용자 탭에 오버레이는 없다.

## Overall Impression

구조는 맞다. 좌 편집·우 미리보기, 저장 전 표시, 항목 번호 짝맞추기는 "편집이 곧 결과"라는 원칙을 실제로 구현했다. 문제는 그 다음 층이다 — **말과 안전장치**. 변호사가 "아이브로우"를 알 리 없고, 삭제 버튼은 물어보지 않고 지운다. 그리고 어드민이 만들어내는 공개 사이트가 접근성 AA를 못 넘는데, 어드민은 그걸 알려주지 않는다. 가장 큰 기회: **어드민이 결과의 품질까지 책임지게 하는 것** — 색을 고르면 대비를 보여주고, 저장하면 저장됐다고 말하는 것.

## What's Working

- **미리보기가 진짜다.** 같은 컴포넌트·같은 변수로 그려서 어긋날 수 없다. 대부분의 CMS 미리보기가 "비슷하게 흉내"인 것과 다르다.
- **입력칸 ↔ 미리보기 요소 짝맞추기.** 커서를 둔 칸이 오른쪽에서 표시되고, 카드는 번호로 이어진다. 첫 사용자가 "이 칸이 어디 나오지?"를 묻지 않는다.
- **토큰 규율.** 어드민 전 화면에 Tailwind 기본 팔레트 직접 사용 0건. 규칙 파일이 있어 팀원 AI 도 유지한다.

## Priority Issues

- **[P0] 삭제가 확인 없이 실행된다.** 블록·항목·페이지 모두. `page_sections` 삭제는 그 안의 항목까지 cascade 로 사라진다.
  - 왜: 변호사가 한 달 만에 들어와 "삭제"를 "닫기"로 착각하면 사례 6개가 사라진다. 되돌리기도 없다.
  - 고침: 삭제 버튼 → 두 단계(버튼이 "정말 삭제" 로 바뀌고 3초 뒤 원복) 또는 인라인 확인. 페이지 삭제는 블록 수를 함께 표시("블록 5개가 함께 삭제됩니다").
  - 명령: `/impeccable harden`

- **[P1] 저장 후 피드백이 없다.** 저장하면 폼이 닫히고 끝. 성공인지, 사이트에 반영됐는지 말하지 않는다.
  - 왜: PRODUCT.md 가 명시한 가장 큰 불안 — "저장했는데 어떻게 됐지?". 미리보기가 저장값으로 돌아가는 것만으로는 부족하다.
  - 고침: 저장 직후 우측 하단(밝기 버튼 위) 토스트 "저장됨 · 사이트에 반영" + 행에 2초간 강조. 실패 시 같은 자리에 빨간 토스트와 재시도.
  - 명령: `/impeccable harden`

- **[P1] 용어가 사용자 것이 아니다.** 아이브로우, CTA 라벨, CTA 링크, slug, 히어로, 배지, 레이아웃 `cards/carousel/list`.
  - 왜: 형사 변호사는 "아이브로우"를 눈썹으로 읽는다. 이름 하나가 막히면 폼 전체가 남의 것이 된다.
  - 고침: 아이브로우 → "작은 제목(위)", CTA 라벨 → "버튼 글자", CTA 링크 → "버튼 누르면 가는 곳", slug → "주소(영문)", 히어로 → "첫 화면 배너". 각 칸 아래 한 줄 예시(placeholder)로 "예: 무료 전화상담".
  - 명령: `/impeccable clarify`

- **[P1] 어드민이 대비 실패를 방치한다.** 홈 스캔 15건의 저대비가 전부 `site_settings.colors` 에서 나왔다.
  - 왜: PRODUCT.md 접근성 기준이 AA 다. 변호사가 색 하나 바꾸면 사이트 전체가 기준 미달이 되는데, 아무도 모른다. 의뢰인 부모 세대가 못 읽는다.
  - 고침: 사이트 설정 색 편집기 옆에 대비 비율 즉시 표시("본문 위 4.5:1 ✓ / 배경 위 3.9:1 ✗"). 프리셋 기본값(`theme_presets`)을 AA 통과 조합으로 교체. 히어로 사진 위에는 스크림(어두운 반투명 막) 토큰 추가.
  - 명령: `/impeccable colorize` (프리셋) + `/impeccable harden` (검사 표시)

- **[P2] 순서를 숫자로 입력한다.** 블록·항목 모두.
  - 왜: "3번을 2번 위로" 하려면 두 행의 숫자를 계산해서 두 번 저장해야 한다. 같은 숫자 두 개도 허용된다.
  - 고침: 행에 ▲▼ 버튼(즉시 저장). 드래그는 그 뒤. 숫자 칸은 숨긴다.
  - 명령: `/impeccable shape` (정렬 인터랙션)

## Persona Red Flags

**유환진 변호사 (첫 사용자, 월 1~2회)**: "페이지 구성" 이 뭔지 모른 채 들어온다. 사이드바에 사이트 열어보기 링크가 없어 결과를 확인할 길이 미리보기뿐. 블록 수정 폼에서 "아이브로우"·"CTA 라벨"에서 멈춘다. 항목 삭제를 눌렀는데 바로 사라져서 놀란다. 저장 후 아무 말이 없어 두 번 누른다.

**개발팀 (오픈 전 대량 입력)**: 사례 6개 넣는 데 항목마다 이미지 업로드·본문·링크 입력. 순서 바꾸려면 숫자 편집. 단축키·복제 없음. 20개 넘으면 편집 목록이 한 화면을 넘어 미리보기와 나란히 보기가 깨진다(sticky 는 유지되지만 스크롤 두 개).

**의뢰인 부모 세대 (공개 사이트, 간접)**: 어드민이 고른 주황 강조가 3.9:1 — 링크·버튼 글자가 흐리다. 히어로 사진 위 흰 글씨는 사진 밝은 부분에서 1.7:1. 이 사람은 어드민을 안 쓰지만 어드민의 결정을 받는다.

## Minor Observations

- 로그인 제목 20px — 카드 안에서 위계가 약하다(탐지기 `flat-type-hierarchy`). 24px 로.
- 편집 폼 상단 4열 `[제목][부제][순서][노출]` — 1280px 미만에서 순서·노출 칸이 답답. 2열+2열.
- 페이지 탭(pill)과 사이드 내비 활성 표시가 다른 문법(채움 vs 틴트). 하나로.
- 사이드바에 "사이트 열기 ↗" 링크가 없다. 미리보기 바깥에서 진짜를 보는 경로가 있어야 한다.
- `/admin` 루트 진입 시 대시보드 없이 바로 어느 화면인지 — 첫 화면에 "오늘 할 일" 성격의 요약(블록 수, 마지막 수정)이 없다.
- 공개 홈: 섹션 kicker 가 slug 대문자(PRACTICE-AREAS). 어드민에서 입력받는 문구가 아니라 코드가 만든 값이 노출된다.

## Questions to Consider

- 변호사가 "페이지 구성"이라는 개념을 알아야 하나? "홈 화면 고치기 / 사례 올리기" 두 개의 일 중심 진입점이면 어떤가.
- 삭제를 없애고 "숨김"만 남기면 안 되나? 되돌릴 수 없는 동작이 화면에 있어야 할 이유가 있는지.
- 어드민이 사이트의 접근성 성적표를 보여준다면, 변호사는 그것을 사무소의 자산으로 느낄까?
